# Iris E看牙 Chrome 扩展

这个扩展把 Iris 悬浮窗嵌入 E看牙页面。

## 使用

1. 运行 `D:\DailyRootine\Iris\Run-Iris.cmd`，启动 Iris 本地服务和 E看牙专用 Chrome。
2. 第一次使用时，在 Chrome 地址栏打开 `chrome://extensions/`。
3. 打开“开发者模式”，点击“加载已解压的扩展程序”。
4. 选择 `D:\DailyRootine\Iris\chrome-extension`。
5. 回到 E看牙页面并刷新，登录后页面右下角会出现 Iris 按钮。
6. 点击 Iris，语音或手动输入复诊要点，生成后填入 E看牙。

## 当前能力与边界

- 只填入，不自动保存（保存永远是医生在 E看牙 手动完成）。
- 初诊：识别主诉、现病史、既往史、口腔检查、辅助检查、诊断、治疗计划、处置、医嘱等字段，按行标签/固定顺序定位；字段无法可靠识别时停止并提示手动补充或复制全文。
- 复诊：填检查/处置/医嘱及主诉/现病史/既往史，并从右侧历史病历栏自动复制上一份正畸复诊的诊断与治疗计划；找不到时提示手动补充。
- 保持器复查走固定模板，不复制旧病历、不加默认医嘱。
- 术语标准化由本地服务按 `D:\DailyRootine\Iris\terms.json` 执行（直接编辑该文件；悬浮窗术语表 UI 已移除）。
- 头侧片截图由本地服务调用 AI 视觉模型识别（见顶层 README / `docs/DECISIONS.md` D-010）。
